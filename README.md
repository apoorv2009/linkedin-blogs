# LinkedIn Blogs

LinkedIn article series by Apoorv Jain (.NET & AI Architect). Each series has its own folder under [series/](series/) with:

- `README.md`: the series index, with a GitHub link and a LinkedIn link for every post,
- `SERIES-PLAN.md`: the plan, roadmap and style guide,
- `articles/`: the posts, with cover images in `articles/images/`.

## Starting a new series

1. Create a folder `series/<short-name>/` with `README.md`, `SERIES-PLAN.md` and `articles/images/`.
2. Add a row to the table above.
